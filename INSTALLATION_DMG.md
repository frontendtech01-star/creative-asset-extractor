# DMG Installation Guide

This guide covers the macOS DMG install for Creative Asset Extractor.

## Download

Download the latest Apple Silicon DMG from the GitHub release page:

[Creative Asset Extractor-1.0.0-arm64.dmg](https://github.com/frontendtech01-star/creative-asset-extractor/releases/download/v1.0.0/Creative%20Asset%20Extractor-1.0.0-arm64.dmg)

## Install

1. Open the downloaded `.dmg` file.
2. Drag `Creative Asset Extractor` into the `Applications` folder.
3. Eject the mounted DMG after the copy finishes.
4. Open `Applications` and launch `Creative Asset Extractor`.

## First Launch

If macOS warns that the app was downloaded from the internet, choose to open it.

If Gatekeeper blocks the first launch:

1. Open `System Settings` -> `Privacy & Security`.
2. Look for the blocked app message near the bottom.
3. Click `Open Anyway`, then launch the app again.

## Notes

- This DMG is for Apple Silicon Macs.
- The local app may show a standard first-run prompt because the build is unsigned.
