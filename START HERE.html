2. macOS installation — Installation guide.md

Right-click the downloaded and extracted folder, select Open Folder in Terminal, paste the command below, and press Return:

xattr -dr com.apple.quarantine . && chmod +x "Run Localhost.command" && ./"Run Localhost.command"

The launcher downloads a private Node.js LTS runtime inside this folder—no administrator password or system installation—then installs dependencies, starts localhost, and opens Chrome.

Windows installation
